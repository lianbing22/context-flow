## 1. SQLite3 WAL 关系数据库与 FTS5 全文检索引擎

### 1.1 背景与设计考量
早期多数记忆类工具或脚本依赖单一扁平的 `data.json` 文件进行全量读写。在频繁的前台窗口切换（每秒多次触碰）和大规模工作足迹积累下，JSON 文件存在两大致命缺陷：
1. **多进程与窗口竞争覆写风险**：旧实例退出钩子容易将过期的内存脏数据回写，导致数据损坏或丢失；
2. **检索性能随数据量线性劣化**：无法建立倒排索引，搜索上万条历史窗口正文时导致主线程严重卡顿。

### 1.2 工业级原生 SQLite 架构
ContextFlow 全面依托 macOS 系统原生 `import SQLite3`（无需任何第三方重型依赖库），落盘于 `~/.contextflow/contextflow.sqlite3`，并预先配置了高性能运行参数：

```sql
PRAGMA journal_mode = WAL;          -- 开启 Write-Ahead Logging 机制，高并发读写互不阻塞
PRAGMA synchronous = NORMAL;        -- 兼顾断电安全性与微秒级磁盘写入性能
PRAGMA cache_size = -8000;          -- 预分配 8MB 内存页缓存
PRAGMA foreign_keys = ON;           -- 保证会话与足迹级联删除的强一致性
```

### 1.3 核心数据表结构
* **`context_sessions`（现场主表）**：记录工作现场的生命周期状态（`active`、`suspended`、`completed`）、专注秒数、所属工程、AI 提炼意图与行动建议；
* **`timeline_events`（细粒度时序足迹流水表）**：精确到毫秒记录每次视窗切换的应用、Bundle ID、窗口标题、URL、编辑的代码文件路径与正文抽取；
* **`fts_timeline`（SQLite FTS5 全文检索虚拟表）**：采用 `tokenize = 'unicode61'` 分词器，针对中英文混合文本建立倒排索引，秒级召回任意业务实体与记忆碎片；
* **`daily_reports`（日报归档表）**：结构化持久化每日专注指标、核心项目突破与明日规划建议。

## 2. 本地大模型运行时与环境配置自适应嗅探 (DeepSeek Harness 机制)

### 2.1 架构理念
借鉴 GitHub 上开源的 **DeepSeek Harness** 与现代 Agent Harness 架构，ContextFlow 强调 **“自适应感知环境（Environment Adaptive）”**。用户无需繁琐查找本地端口或四处复制 API Key，系统启动时或在设置中一键即可实现全域自适应发现。

```
┌──────────────────────────────────────────────────────────────────┐
│                   ModelDetector 并发探测引擎                     │
├───────────────────┬──────────────────────────┬───────────────────┤
│ 本地大模型端口探测 │  环境变量与 Shell 扫描   │ 客户端配置与 IDE  │
│  - Ollama (11434) │  - DEEPSEEK_API_KEY      │  - Antigravity    │
│  - LM Studio (1234│  - OPENAI_API_KEY        │  - Cursor/VSCode  │
│  - vLLM (8000)    │  - ZHIPU_API_KEY         │  - Claude Desktop │
│  - LocalAI (8080) │  - SILICONFLOW_API_KEY   │  - WeChat DevTools│
└───────────────────┴──────────────────────────┴───────────────────┘
```

### 2.2 探测执行逻辑
1. **本地大模型端口并发嗅探**：通过非阻塞的并发 `async/await` 探测 `127.0.0.1` 上的主流端口。若 Ollama 在线，自动请求 `/api/tags` 解析已下载的离线模型（如 `deepseek-r1:8b`、`qwen2.5:7b`）；
2. **环境变量与 Shell Profile 穿透**：无感扫描当前进程环境变量及 `~/.zshrc`、`~/.bash_profile`，安全提取用户此前配置过的各厂商模型密钥；
3. **一键自动装配 (One-Click Adopt)**：在 UI 上直观展示发现的端点与密钥，用户点击“一键装配”即可自动将端点、模型代号填入配置，并将有效 Key 汇入高可用密钥池。

## 3. 高可用多 API Key 智能轮换池与 Failover 故障转移

### 3.1 痛点解决
在高频的工作记忆意图提炼与连续自然语言问答中，单 Key 极易触发服务商的并发限制（429 Rate Limit）或因公网抖动发生连接超时。

### 3.2 轮换与容灾算法
* **密钥池自动解析**：支持多行换行或逗号分隔录入多个 API Key，系统自动剔除重复项并组建通道池；
* **Round-Robin 负载均衡**：并发请求按循环顺序轮换分配，降低单 Key 的限流概率；
* **毫秒级故障转移 (Failover)**：
  - 当某个通道遭遇 HTTP 429、401 鉴权失效或请求超时，系统立即标记该通道并无缝切换至备用通道重试；
  - 只有当池内所有 Key 均告耗尽时，才优雅降级至端侧离线引擎；
* **开箱即用离线端侧保障**：在无网络或未填写 Key 的状态下，系统自动启用 Apple Neural Engine（本地 CoreML / Vision）进行离线实体提炼，完全离线可用。

## 4. 毫秒级视窗穿透与 IDE 侧边栏防幻觉降噪屏障

### 4.1 双层感知探查链
1. **CoreGraphics 毫秒级轻量探查**：优先通过 `CGWindowListCopyWindowInfo` 原生 API 获取前台顶层有效在屏窗口（`layer == 0`，排查掉极小气泡与无意义透明窗口）；
2. **Accessibility 深度正文穿透**：通过无感 AppleScript / AXUIElement 探查真实网页标签页标题（Chromium 系与 Safari 系）、正在编辑的工程源码路径。

### 4.2 IDE 侧边栏降噪与防幻觉屏障
在开发环境（如 Antigravity、VS Code、Claude）中，侧边栏通常充斥着大量旧会话标题或历史杂项列表。若直接无差别抓取 Static Text，大模型提炼意图时极易产生荒谬幻觉（例如误把旧历史当成今天正在开发的项目）。

ContextFlow 实施了双重硬核防线：
1. **探查层黑名单过滤**：在抓取 Accessibility 元素时，严格过滤包含侧边栏导航条目、历史列表关键词的噪音文本；
2. **宿主精准绑定**：针对当前宿主环境（如 Antigravity），系统自动将其工程锁定为真实的 `全局记忆精灵 (ContextFlow)`，并强制要求大模型基于真实客观代码足迹作答，彻底根绝无中生有的幻觉。

## 5. 阶跃星辰风格现代桌面端 UI 与多语言国际化 (i18n)

### 5.1 界面美学规范
* **宽屏自适应架构**：采用三栏通透视觉（左侧导航栏、中间时间轴流水、右侧全景视窗 Inspector），支持自由拖拽缩放与全屏排布；
* **消灭系统 TabView 缺陷**：放弃 macOS 原生容易产生反人类悬浮黑条与 `>>` 溢出的 TabView，改用原生平铺的高档胶囊分段导航；
* **5 套精调视觉主题**：
  * **阶跃暖橘 (StepFun Amber)**：对齐商业级灵动高质感暖橙；
  * **极光深邃 (Aurora Deep)**：夜间沉浸式极光蓝绿；
  * **电光紫霓 (Electric Neon)**：高对比度极客霓虹紫；
  * **极简纸墨 (Minimal Paper)**：极简素雅纯粹白纸；
  * **跟随系统 (System Native)**：深度融入 macOS 原生浅色与深色外观。

### 5.2 多语言国际化 (i18n)
内置 `LocalizationManager.swift`，全面支持：
* 🇨🇳 **简体中文 (zh-Hans)**
* 🇺🇸 **English (en)**
* 🇯🇵 **日本語 (ja)**

用户可在偏好设置中自由切换，所有主界面、菜单、对话框均即时响应换肤换语言，无需重启应用。

## 6. 工作全景复盘日报与周报投入占比算法

### 6.1 今日全景复盘日报
* **专注指标聚合**：精确统计全天累计专注时长与处理的工作现场个数；
* **核心业务综述**：由 AI 深度提炼关键业务突破，严格过滤车轱辘套话；
* **明日行动清单**：智能推导下一步优先推进事项；
* **一键复制 Markdown**：导出排版优美的标准 Markdown。

### 6.2 本周全景周报与研发投入占比分析
* **跨 7 天历史流聚合**：聚合过去一周的所有有效专注现场；
* **项目时间投入占比算法**：
  $$\text{Percentage}_i = \frac{\text{FocusMinutes}_i}{\sum_{j} \text{FocusMinutes}_j} \times 100\%$$
* **可视化进度条**：直观展示各个项目或模块的时间投入比例；
* **每日脉络追踪与下周规划**：帮助团队与个人清晰把握阶段性推进节奏。

## 7. 端侧隐私与长效权限锁定机制

* **0 截图上云原则**：工作现场离开瞬间的视窗快照与 OCR 均在本地计算，绝不上传云端服务器；
* **系统级敏感应用永不嗅探**：1Password、KeePassXC、系统锁屏与钥匙串访问等安全进程默认永久拦截；
* **固定 Designated Requirement 代码签名**：
  在编译时锁定 `identifier "app.memoryelf" and anchor apple generic` 指定要求，确保每次构建与升级后 macOS 系统安全策略始终予以信任，彻底终结重启后反复请求系统权限的恶劣体验。
